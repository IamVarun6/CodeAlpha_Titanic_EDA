# Titanic Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset.

## Objectives
- Explore dataset structure
- Identify trends and patterns
- Test hypotheses using statistics and visualizations
- Detect data quality issues

## Dataset Information

The Titanic dataset contains passenger information such as:

- Passenger Class
- Gender
- Age
- Fare
- Cabin Information
- Survival Status

Total Records: 891
Total Features: 12

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

### Data Inspection

- Dataset Structure
- Variable Types
- Missing Values Analysis

### Statistical Analysis

- Descriptive Statistics
- Distribution Analysis

### Visualization

- Survival Distribution
- Gender Distribution
- Gender vs Survival
- Passenger Class vs Survival
- Age Distribution
- Age vs Survival

### Hypothesis Testing

1. Female passengers were more likely to survive.
2. First-class passengers had higher survival rates.
3. Younger passengers had better chances of survival.

---

## Key Findings
- Survival rate was approximately 38.4%
- Female passengers had a higher survival rate than males
- First-class passengers were more likely to survive
- Most passengers were between 20 and 30 years old
- Missing values existed in Age, Cabin, and Embarked columns

## Conclusion

The analysis revealed that gender and passenger class were the strongest factors influencing passenger survival. Age also showed some influence, although less significant compared to gender and class.
